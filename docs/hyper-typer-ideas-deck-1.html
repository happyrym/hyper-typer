Reliability · Speed

워밍 세션 (Warm Session)

생성 지연 9~64초 → 일정한 2~5초, 타임아웃 실패 제거. 지금 안정성의 최대 병목.

왜

매 호출이 claude -p 콜드 스타트라 컨텍스트를 매번 다시 로드(첫 토큰 전 시간이 대부분). 편차가 커서 가끔 워치독에 잘려 fallback.

어떻게

지속 claude 프로세스를 stream-json 입출력으로 띄워 재사용. 첫 호출만 느리고 이후는 예열 상태라 즉답.

효과

"타이밍이 안 맞는다"의 근본 해결. 답변 기반이든 엔터 기반이든 즉시 체감.

리스크

프로세스 수명·에러 복구·동시성 관리 필요. 세션 상태가 누적되지 않게 매 요청 격리.

난이도 중~높음임팩트 최상
Hyper Typer
2
Multi-terminal

터미널별 정보·요약

여러 터미널을 오갈 때 각 세션의 cwd·브랜치·직전 교환 요약을 패널에 함께 표시.

왜

세션이 많으면 지금 후보가 '어느 터미널' 것인지 헷갈림. 정보/요약이 붙으면 신뢰가 생긴다.

어떻게

쉬움: 스코핑된 세션의 cwd/직전 프롬프트를 info 헤더로. 어려움: 포커스 창→세션 매핑(화면기록 권한+창 제목, 또는 Orca pane 데이터)으로 '보는 즉시' 전환.

효과

submit 기반 스코핑(이미 구현)에 정보 표시만 얹어도 큰 개선. 포커스 추종은 그 위 단계.

리스크

정확한 창→세션 매핑은 macOS/Orca가 표준 노출 안 해 난도 높음(권한·취약성).

난이도 중~높음임팩트 높음

3
Input UX

단축키 즉시 붙여넣기

⌘⌥1~5로 후보를 Orca에 바로 삽입 — 복사+⌘V 두 동작이 한 키로.

왜

지금은 복사 버튼→수동 붙여넣기(2동작). 핫키 한 번이면 진짜 '가속기'가 된다.

어떻게

전역 핫키 등록 → 후보 N을 클립보드에 넣고 합성 ⌘V 전송. Accessibility 권한 1회 필요.

효과

패널을 '보고 고르는' 것에서 '한 키로 발사'로. 초기부터 미뤄둔 핵심 UX.

리스크

Secure Input 구간에선 합성 키 차단 가능 → 상태 감지해 복사 폴백.

난이도 중임팩트 높음

4
Personalization

개인화 랭킹 · 프롬프트 사전

내가 실제로 복사한 후보를 학습해 랭킹을 개선하고, 자주 쓰는 프롬프트를 사전으로 축적.

왜

범용 제안은 곧 식상. '나에게 꼭 맞는'이라는 원래 컨셉의 심장. 쓸수록 좋아져야 한다.

어떻게

복사·채택 이벤트를 로컬 로깅 → 빈도·문맥으로 후보 재랭킹. 반복 프롬프트는 '슬래시 사전'으로 승격 제안.

효과

장기 차별화 축. LLM 후보 + 내 사전을 섞어 명중률↑, 생성 비용·지연↓.

리스크

로그는 전량 로컬·프라이버시. 콜드스타트는 규칙, 데이터 쌓이며 학습층 대체.

난이도 중임팩트 높음(장기)

5
Quality

컨텍스트 인식 · 구조화 후보

현재 diff·에러·repo를 근거로 더 날카롭게, 또는 진행/검증/대안으로 구조화·스트리밍.

왜

답변만 보면 놓치는 맥락(방금 난 에러, 변경 파일)이 다음 프롬프트를 좌우. 후보 품질의 다음 도약.

어떻게

생성 프롬프트에 git status·최근 에러 요약 주입. 후보에 카테고리 태그. stream-json으로 부분부터 즉시 표시.

효과

"이미 한 걸 또 시키는" 실수 감소, 상황 특화 제안. 스트리밍으로 체감 지연도 완화.

리스크

컨텍스트 과다 주입 시 지연·비용↑. 필요한 것만 요약해 투입.

난이도 중임팩트 중~높음
