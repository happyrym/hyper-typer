Hyper Typer · v0 MVP

Orca 위에 떠서 다음 프롬프트 5개를 던져주는 플로팅 패널

직전 AI 답변을 읽어 "다음에 보낼 만한 프롬프트" 5개를 제안하고, 복사 버튼으로 클립보드에 넣어 Orca에 붙여넣게 한다. API 키·결제 없이 로컬 claude CLI로 생성. 자동 주입이 없어 Secure Input·HID·AX 문제를 통째로 회피한다.

● 동작 중 — 빌드·실행·자동갱신·CLI 후보·복사 검증 완료 (2026-08-24)

1 어떻게 도나 — 데이터 흐름

키 입력을 가로채지 않는다. 답변을 읽고, 후보를 생성하고, 복사만 한다.

1
답변 감지
Claude Code가 답을 끝내면 ~/.claude/projects/…/<session>.jsonl에 append. FSEvents가 감지(0.8s 디바운스). subagents/ 제외.
2
직전 답변 추출
최신 jsonl에서 마지막 assistant 턴의 text 블록만 뽑음(message.id 그룹핑, thinking/tool_use 버림).
3
후보 생성 (키리스)
claude -p --model haiku print 모드로 "다음 프롬프트 5개"를 JSON 배열로 받음. 로그인된 Claude Code 인증 사용 → 키 불필요(~5-10초).
4
패널 렌더 & 복사
Orca 창 위 플로팅 패널에 5줄 + 복사 버튼. 클릭 → NSPasteboard → Orca에 수동 붙여넣기. 자동 전송 없음.

3 실행 방법

cd HyperTyper
swift build
./.build/debug/HyperTyper &      # 키 불필요 — claude CLI 사용
killall HyperTyper               # 종료

패널 빈 곳을 드래그해 원하는 자리로 옮기면 유지된다. ↻ 버튼으로 수동 재생성. Orca 위에 뜨고 포커스는 안 뺏는다.

4 핵심 설계 결정

키리스 — claude CLI 경유

Anthropic API 키·결제 대신 이미 로그인된 claude CLI를 print 모드로 호출. 사용량은 소모, 지연 ~5-10초.

복사-붙여넣기 = 주입 대체

자동 키 주입을 포기해 HID 엔진·Secure Input·AX 커서 좌표 하드 리스크를 전부 우회. 2동작(복사→⌘V)이지만 즉시 빌드 가능.

창 레벨 앵커링

글자 셀 좌표(Orca=Electron이라 취득 불가) 대신 창 프레임만 사용(CGWindowList). 드래그-유지 + 이동량 추종.

파킹된 큰 그림

원래 4개(SeamLayer·ChordTap·LeaderKey·다음수예측)의 HID 엔진 통합은 뒤로. 이 MVP로 "후속 프롬프트가 도움되나"부터 검증.
