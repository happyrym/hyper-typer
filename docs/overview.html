hyper-typer

당신의 다음 프롬프트를 예측하는
AI 보조 입력 도구

Orca 터미널 위에 떠서, 포커스된 터미널의 직전 대화를 읽어 "다음에 보낼 만한 프롬프트 후보 5개"를 제안하고 복사 버튼으로 클립보드에 넣어 붙여넣게 하는 네이티브 macOS 플로팅 패널. API 키·결제 없이 로컬 claude CLI로 생성한다.

● 동작 중 · macOS 13+ · Orca 전용

1 컨셉

무엇

프롬프트를 칠 때마다 "다음에 보낼 말" 5개를 옆에 띄우는 보조 입력기. 고르면 복사되고 붙여넣기만 하면 된다.

왜

LLM 코딩에서 "빈 입력창을 마주하고 뭘 칠지 고민하는 시간"이 숨은 병목. 그 다음 한 수를 미리 깔아 준다.

어떻게

키·결제 없이 로컬 claude CLI로 생성. 자동 주입이 없어 Secure Input·접근성 권한 문제를 회피한다.

터미널별

여러 Orca 터미널을 오갈 때 지금 포커스된 터미널의 세션 맥락으로 후보를 낸다. 터미널마다 캐시해 전환은 즉각적.

2 동작 흐름

키 입력을 가로채지 않는다. 답변을 읽고, 후보를 생성하고, 복사만 한다.

1
포커스 감지
Orca 상태 파일(orca-data.json·last-status.json)을 FSEvents로 감시 → 지금 포커스된 pane과 그 세션(cwd·상태·직전 프롬프트·답변) 해석.
2
턴 완료 판정
어시스턴트 답변이 완료됐을 때 그 답변을 근거로 생성(진행 중엔 대기) → "당신이 칠 다음 프롬프트"를 예측.
3
후보 생성
claude -p --model haiku로 후보 5개. 격리 실행으로 자기 트리거 방지. pane별 캐시로 왕복 무지연.
4
표시·복사
포커스 창 위 플로팅 패널에 5줄 + 복사 버튼. 붙여넣기는 수동(⌘V).

3 빠른 설치 (프롬프트 복붙)

아래를 Orca의 Claude Code에 붙여넣으면 알아서 설치·실행합니다.

하이퍼 타이퍼(hyper-typer)를 내 Mac에 설치하고 실행해줘. Orca 터미널에서 Claude Code로 작업할 때,
포커스된 터미널 위에 "다음에 보낼 프롬프트 후보 5개"를 띄워주는 보조 도구야. 순서대로 진행하고 막히면 고쳐줘.
1. 사전 점검: macOS 13+, swift(안 되면 xcode-select --install), claude(로그인·키 불필요), Orca 사용 여부
2. 설치: ~/hyper-typer 없으면 git clone https://github.com/happyrym/hyper-typer.git ~/hyper-typer
3. 빌드·실행: cd ~/hyper-typer && ./build-app.sh && open ~/hyper-typer/HyperTyper.app
4. 확인: 메뉴바 ✨ + Orca 위 패널이 뜨는지

수동 설치: git clone … && cd hyper-typer && ./build-app.sh && open HyperTyper.app · 종료·글씨 크기는 메뉴바 ✨에서.

5 기능 & 요구사항

  • 포커스 터미널별 후보 (Orca 상태 기반)
  • pane별 캐시 → 전환 즉각적
  • 키리스 (claude CLI, API 키 불필요)
  • 복사 버튼 → 붙여넣기 (자동 주입 없음)
  • 글씨 크기 5단계 (저장)
  • 패널 위치·크기 기억
