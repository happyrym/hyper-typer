Hyper Typer · Unified Design v1

4개 컨셉을 한 몸으로 — macOS·터미널 프롬프트 가속기

채택한 넷(다음 수 예측 · SeamLayer · ChordTap · LeaderKey)을 하나의 로컬 개인화 코어를 공유하는 단일 앱으로 통합. 심층 설계 → 가장 위험한 기술 가정 9건 적대적 검증 → 통합 아키텍처 합성의 결과입니다.

검증에서 뒤집힌 핵심 전제 3가지

① 네 기능의 입력 엔진은 CGEventTap이 아니라 Karabiner-DriverKit(HID 계층)이어야 한다 — 터미널의 Secure Input(sudo·ssh·Secure Keyboard Entry)이 CGEventTap을 시스템 전역으로 죽인다. HID 가상키보드만 그 아래로 통과.
② 실제 터미널이 Orca(Electron+xterm.js, GPU 렌더)라 셀 커서 좌표를 AX로 못 얻는다 → 커서에 붙는 인라인 고스트텍스트는 포기, 화면 하단 고정 힌트 바로.
③ 다음 수 예측의 '직전 답변 읽기'는 화면 스크래핑이 아니라 Claude Code hook/transcript(JSONL) 정본 채널로 — Secure Input이 못 막는 유일한 경로.

A 아키텍처 — 4개 수직 레이어

하나의 탭이 아니라 관심사별로 쌓고, 횡단 관심사(Secure Input·IME 조합·방출 중재)는 공유 모듈로 분리.

L1 입력 엔진 — HID 계층 키 인터셉트/방출

물리 키보드를 root DriverKit 가상 HID로 잡아 리맵·momentary 레이어·chord 판정·leader 트라이를 IME '아래'에서 처리. 한글 포함 구문은 클립보드+paste 폴백. CGEventTap은 수락키 소비·상태 감지 보조로만.
SeamLayerChordTapLeaderKey예측 Tab 수락 주입
기술 Karabiner-DriverKit-VirtualHIDDevice(root) + kanata(defchordsv2 concurrent-tap-hold, defseq leader, layer-while-held) · 방출은 가상 HID + osascript 클립보드 폴백(LC_ALL=en_US.UTF-8)

L2 개인화 코어 — 로컬 프롬프트 로그 + n-gram 마이닝

모든 프롬프트·키스트로크·수락/기각 신호를 로컬에만 저장하고 온디바이스로 마이닝. 4개 컨셉이 공유하는 단일 저장소. 야간 배치 + 온라인 증분. 쓸수록 나에게 최적화.
공유 templates/turn_eventschord 자동배치(가중 이분매칭)영문 토큰 승격 사전니모닉 자동배정후속습관 조건부확률
기술 로컬 SQLite(민감필드 마스킹) · 오프라인 설정 생성기가 로그→n-gram→kanata config 렌더 · 클라우드 미전송·옵트인

L3 예측층 — 정본 읽기 + 다음 수 생성

Claude Code hook(Stop/UserPromptSubmit)과 transcript JSONL을 tail-파싱해 직전 어시스턴트 턴과 '턴 종료' 신호를 정본으로 취득(AX 스크래핑 금지). 출력 종류×후속습관으로 검색+재랭킹해 다음 프롬프트 후보 생성.
다음 수 예측위험토큰 필터(rm -rf/force push)콜드스타트 규칙 3분기
기술 Claude Code hooks JSONL + Orca agent-hook 엔드포인트(리버스 필요) · 검색+재랭킹 우선, 온디바이스 LLM 후순위 · 폴백 tmux capture-pane/OSC133

L4 HUD — 오버레이 렌더 매니저

click-through 반투명 NSPanel 하나로 4개 컨셉의 온스크린 요소를 그린다. 커서 정합 인라인은 기본 포기, 화면/창 하단 고정 바가 기본값.
예측 고스트(하단 힌트 바)LeaderKey which-key 팔레트ChordTap 발화 플래시EN/KO 뱃지Secure Input degrade 배너
기술 NSPanel(borderless·.floating·ignoresMouseEvents) · iTerm2 한정 AX 리드백으로 근사 인라인 옵트인, 그 외 HUD-only degrade

B 핵심 기술 결정

입력 엔진

커스텀 CGEventTap을 주경로에서 배제, Karabiner-DriverKit + kanata를 1급 엔진으로. Secure Input이 CGEventTap을 전역으로 굶기는데 HID 가상키보드는 그 아래로 통과. SeamLayer의 IME 공존 난제도 IME '아래' 리맵일 때만 구조적 회피.

검증: 조건부가능 (conf 0.78)

예측 표면 (읽기/쓰기 분리)

읽기 = hook/transcript 정본(Secure Input 무관). 쓰기 = 커서 정합 인라인 포기, 하단 고정 힌트 바. 수락키는 Tab(Claude Code와 충돌)→우엄지+space chord로 재배치. 인라인은 iTerm2 한정 베타.

검증: 조건부가능 (conf 0.72)

개인화 코어

단일 로컬 SQLite가 4개 학습 원천이자 프라이버시 경계. 후속습관 n-gram·문체·chord 배치·영문 토큰·슬롯 히스토리. 전량 온디바이스·마스킹·옵트인·되돌리기 1키. Secure Input 구간 캡처 스킵.

콜드스타트: 규칙 3분기 → 학습층 대체

방출 중재

SeamLayer(홀드)·ChordTap(chord)·LeaderKey(leader)가 같은 홈로우 스트림을 두고 경합 → 단일 상태기계가 결정론적 라우팅. 실패/타임아웃 시 소비 프리픽스를 원순서·원타이밍으로 replay해 손실 방지.

modifier 활성 시 셋 다 판정 안 열고 통과

C 단계 로드맵 — 쉬운·검증된 것부터, 어려운 예측은 뒤로

적대적 검증에서 '어려움'이 나온 건 후순위. 커서 좌표가 필요 없는 기능을 먼저 체감시킨다.

P0 · 2~3주
공유 인프라 부트스트랩 — 체감 기능 없이 토대만, 위험 검증 병행
  • Karabiner-DriverKit + kanata 온보딩 위저드(TCC 4종)
  • 로컬 SQLite 개인화 코어 + 프롬프트 로거
  • Secure Input 게이트·IME 조합 감시·표면 판별기
  • 키보드 rollover/고스팅 캘리브레이션 · hook/transcript 스키마 리버스
산출물: 권한 승인 완료 + 로그 수집 시작 + Secure Input/조합 상태 감지 헬스체크
토대
P1 · 2~3주
SeamLayer — 가장 빨리 체감, 좌표 불필요, '검증됨' 경로
  • kanata layer-while-held 순수 ASCII 레이어(입력소스 미전환)
  • IME 조합 경계 명시적 flush + 상태 검증 게이트
  • EN/KO 뱃지 HUD · 영문 토큰 승격 사전(옵트인)
산출물: 엄지 홀드 영문 입력이 sudo 구간 포함 무결 동작, 조합 유실 회귀테스트 통과
첫 체감
P2 · 4~5주
ChordTap + LeaderKey — 좌표 불필요, 방출 중재 확립
  • defchordsv2 chord(3키·매트릭스 독립·상태의존 게이팅) + n-gram 자동배치
  • leader 트라이 상태기계 + which-key 팔레트(NSPanel)
  • 한글 구문 클립보드 paste 방출 · 방출 우선순위 중재자 확정
산출물: chord로 15~40자 구문, 리더키로 문체 템플릿, 산문 오발 <1/1000, 세 기능 충돌 없이 공존
핵심 가속
P3 · 5~7주
다음 수 예측 — 가장 어려움, 후순위
  • hook/transcript 정본 읽기 + 턴 종료 감지
  • 검색+재랭킹 후보 생성 + 위험토큰 필터
  • 하단 고정 힌트 바 렌더 · 우엄지+space로 HID 주입
  • iTerm2 한정 근사 인라인 옵트인 베타
산출물: 턴 종료 후 힌트 바 후보, 오탐 억제(신뢰도 임계·연속기각 침묵), 자동전송 없음
지능화

E 남은 결정 (스펙 전 확정 필요)

  1. Orca agent-hook 프로토콜 — ORCA_AGENT_HOOK_ENDPOINT/PORT로 직전 턴+종료 구독 가능한지 (엔드포인트 실재, 문서 없음 → P0 리버스)
  2. Claude Code transcript 안정성 — 2.1.x JSONL 경로·스키마와 Stop hook 최종 텍스트의 버전 안정성 (실측)
  3. 예측층 방식 — 검색+재랭킹 유지 vs 소형 온디바이스 LLM 승격 (콜드스타트 품질 ↔ 상시 메모리/전력)
  4. 예측 수락키 — Tab 재배치 vs 우엄지+space chord (오발동률·학습곡선 A/B)
  5. SeamLayer 엄지키 위치 — 우Cmd/재매핑 Space/한자키 중 홀드 분포 로그로 피로 최소값
  6. IME 지원 범위 — 2SetKorean 외 세벌식/구글 IME·다국어 3중 전환 (레이어 스택 설계 시점)
